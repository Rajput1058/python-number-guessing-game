# 🎮 Python Number Guessing Game

A fun interactive number guessing game built with Python! Part of my Python learning journey in Lisbon.

## 🚀 Features
- Random secret number between 1-99
- 7 attempts limit (like real game security!)
- Hints: Too High / Too Low
- Attempts counter
- Game Over if you fail!
